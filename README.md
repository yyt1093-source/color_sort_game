# 🧪 Color Sort — Telegram Mini App (24/7 Cloud Game)

Увлекательная головоломка с переливанием жидкостей для Telegram Mini Apps с бесконечными уровнями, поддержкой звуковых эффектов (Web Audio API), рекламой Adsgram и круглосуточной работой в облаке 24/7!

🎮 **Играть онлайн 24/7:** [https://yyt1093-source.github.io/color_sort_game/](https://yyt1093-source.github.io/color_sort_game/)

🤖 **Telegram Бот:** [@sortcolors_bot](https://t.me/sortcolors_bot)

---

## ✨ Возможности
- ♾️ **Бесконечные уровни:** 100% гарантированная решаемость благодаря A* решателю и Mulberry32 PRNG.
- 🎨 **Красивая графика и эффекты:** Анимированное переливание жидкостей, частицы конфетти, стеклянные баночки.
- 🎵 **Процедурный синтезатор звуков:** Звуки бульканья воды, кликов и победы генерируются через Web Audio API.
- 📺 **Adsgram Rewarded Video:** Реклама с начислением бонусов (подсказки, отмены, дополнительные колбы).
- ☁️ **Работает при выключенном компьютере:** Развернуто на GitHub Pages (Frontend) и Render (Node.js Backend / Bot).
